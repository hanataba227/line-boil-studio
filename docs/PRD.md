# PRD: Line Boil Studio

## 1. 개요

| 항목            | 내용                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------ |
| **프로젝트명**  | Line Boil Studio                                                                           |
| **한줄 설명**   | 이미지를 업로드하면 Line Boil(선 떨림) 효과를 적용한 GIF를 생성·다운로드할 수 있는 웹 도구 |
| **타겟 사용자** | 디자이너, 일반인                                                                           |
| **플랫폼**      | 웹 (Streamlit)                                                                             |
| **배포**        | Streamlit Community Cloud                                                                  |

## 2. 배경 및 문제 정의

**Line Boil**은 애니메이션에서 프레임마다 선이 미세하게 떨리는 효과로, 손으로 그린 듯한 생동감을 부여한다. 이 효과를 만들려면 기존에는:

- 일러스트레이터/애니메이터가 수작업으로 프레임별 선을 다시 그림
- After Effects 등 유료 전문 소프트웨어 사용

**해결**: AI 없이 알고리즘 기반으로 이미지 한 장에서 자동으로 Line Boil GIF를 생성하여, 누구나 간단하게 사용할 수 있도록 한다.

## 3. 사용자 흐름 (User Flow)

```
이미지 업로드 (PNG/JPG)
    ↓
원본 이미지 미리보기
    ↓
파라미터 조절
  - 프레임 수 (기본: 3)
  - FPS (기본: 8)
  - 이미지 크기 (가로/세로)
  - 선 변형 강도
    ↓
[생성] 버튼 클릭
    ↓
Line Boil GIF 미리보기 (애니메이션)
    ↓
[다운로드] 버튼 → GIF 파일 저장
```

## 4. 핵심 기능 명세

### 4.1 이미지 업로드
| 항목        | 내용                                                   |
| ----------- | ------------------------------------------------------ |
| 지원 포맷   | PNG, JPG/JPEG                                          |
| 업로드 방식 | Streamlit `file_uploader` (드래그 앤 드롭 / 파일 선택) |
| 제한        | Streamlit Community Cloud 기본 업로드 제한 (200MB)     |

### 4.2 Line Boil 생성 엔진 (알고리즘 기반, 비-AI)

**처리 파이프라인:**

1. **전처리**: 업로드 이미지를 그레이스케일로 변환
2. **엣지 추출**: Canny Edge Detection으로 윤곽선 추출
3. **프레임 생성**: 설정된 프레임 수만큼 반복
   - 윤곽선 좌표에 랜덤 미세 변형 (displacement) 적용
   - 선 두께에 랜덤 변형 적용
   - 변형 강도는 사용자 설정값에 비례
4. **GIF 합성**: 생성된 프레임들을 설정된 FPS로 GIF 합성
   - 배경: **투명**
   - 루프: 무한 반복

### 4.3 파라미터 조절

| 파라미터            | 기본값         | 범위        | UI 컴포넌트          |
| ------------------- | -------------- | ----------- | -------------------- |
| 프레임 수           | 3              | 2 ~ 12      | 슬라이더             |
| FPS                 | 8              | 1 ~ 24      | 슬라이더             |
| 출력 크기 (가로)    | 원본 비율 유지 | 64 ~ 2048px | 숫자 입력            |
| 선 변형 강도        | 중간 (50%)     | 0% ~ 100%   | 슬라이더             |
| Canny 임계값 (low)  | 50             | 10 ~ 200    | 슬라이더 (고급 옵션) |
| Canny 임계값 (high) | 150            | 50 ~ 400    | 슬라이더 (고급 옵션) |

### 4.4 미리보기
- 원본 이미지 미리보기
- 엣지 추출 결과 미리보기 (파라미터 조절 시 실시간 갱신)
- 생성된 GIF 애니메이션 미리보기

### 4.5 다운로드
- GIF 파일 다운로드 (`st.download_button`)
- 파일명: `lineboil_{원본파일명}_{timestamp}.gif`

## 5. 기술 스택

| 구분            | 기술                         |
| --------------- | ---------------------------- |
| **프레임워크**  | Streamlit                    |
| **이미지 처리** | OpenCV (cv2), Pillow (PIL)   |
| **엣지 추출**   | OpenCV Canny Edge Detection  |
| **GIF 생성**    | Pillow (GIF 합성, 투명 배경) |
| **수학/랜덤**   | NumPy                        |
| **배포**        | Streamlit Community Cloud    |
| **언어**        | Python 3.11+                 |

## 10. 성공 지표

- 이미지 업로드 후 GIF 생성까지 **10초 이내** (일반적인 크기)
- 생성된 GIF에서 **자연스러운 Line Boil 효과** 확인
- 비개발자도 **3클릭 이내**에 GIF 생성 가능
